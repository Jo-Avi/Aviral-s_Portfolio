# 🌐 Personal Portfolio Website

Welcome to my personal portfolio! This website showcases my technical skills, projects, education, and professional experience in **Data Analytics, Web Development, and AI/ML**.

🔗 **Live Demo:** [aviralportfolio-six.vercel.app](https://aviralportfolio-six.vercel.app/)

## 📌 About the Project

This portfolio website serves as a central place to explore my technical expertise, featured projects, and professional journey. It features a clean, responsive design that provides an accessible browsing experience across different devices.

## ✨ Features

* **About Me:** Introduction and professional background.
* **Skills:** Overview of my technical and professional skills.
* **Projects:** Showcases my projects across Data Analytics, Web Development, and AI/ML.
* **Education:** Academic qualifications and background.
* **Experience:** Highlights my internship and professional experience.
* **Contact:** Ways to connect with me professionally.
* **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

* **HTML5** – Website structure
* **CSS3** – Styling, layouts, and responsive design
* **JavaScript** – Interactive elements and functionality
* **Vercel** – Deployment and hosting

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

* A modern web browser
* Git installed on your system

### Installation

1. Clone the repository:

   ```bash
   git clone <[your-github-repository-url](https://github.com/Jo-Avi/Aviral-s_Portfolio.git)>
   ```

2. Navigate to the project directory:

   ```bash
   cd <your-project-folder>
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
